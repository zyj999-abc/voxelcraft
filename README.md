# VoxelCraft — 浏览器体素沙盒游戏

一款**完全运行在浏览器中**的类 Minecraft 体素沙盒游戏。纯原生 JavaScript + Three.js (WebGL) 实现，
**零依赖后端、零外部资源** — 全部材质均由程序化生成，打开即玩。

> 原创实现，与 Mojang / Microsoft 无关。

## 🎮 在线游玩

**[点击这里开始游戏](https://zyj999-abc.github.io/voxelcraft/)**

推荐使用 Chrome / Edge / Firefox 最新版，需要 WebGL 支持。

## ✨ 核心特性

### 世界生成
- 无限程序化地形：大陆噪声 + 山脊噪声 + 细节噪声
- 7 种生物群系：海洋 / 沙滩 / 平原 / 森林 / 沙漠 / 针叶林 / 山地
- 立体洞穴系统（ spaghetti + cheese 双通道雕刻）
- 矿脉生成：煤 / 铁 / 金 / 钻石，按深度分布
- 植被：橡树 / 白桦 / 云杉 / 仙人掌 / 花草
- 世界种子支持（相同种子 = 相同世界）

### 方块与交互
- 45+ 种方块，带硬度 / 工具需求 / 掉落规则
- 破坏进度动画 + 粒子效果
- 方块放置 / 选取（中键）
- 环境光遮蔽 (AO) 平滑光照
- 半透明水面渲染

### 生存玩法
- 生命值 / 饥饿值 / 氧气（水下呼吸）
- 摔落伤害 / 溺水伤害 / 火焰伤害
- 死亡掉落物品 + 重生
- 完整合成系统：2x2 随身合成 + 3x3 工作台
- 熔炉冶炼：矿石 → 锭，生肉 → 熟肉
- 20+ 合成配方，5 材质 x 4 类型工具

### 生物
- 被动生物：猪（掉落猪排）
- 敌对生物：僵尸（夜晚生成，追踪玩家）
- 简单 AI：游荡 / 追击 / 攻击
- 掉落物实体：旋转漂浮，靠近拾取

### 世界交互
- TNT 爆炸（连锁引爆 + 破坏地形）
- 火把照明
- 昼夜循环：日月星辰 / 程序化云层 / 日落色彩
- 动态雾效（跟随渲染距离）

### 界面与系统
- 类 MC 像素风 UI：标题画面（随机 splash）/ HUD / 背包 / 合成 / 熔炉
- 创造模式：飞行（双击空格）/ 无限方块 / 免伤害
- 聊天命令：`/give` `/time` `/tp` `/gamemode` `/help`
- 存档系统：localStorage 自动保存 + 手动保存
- F3 调试信息（FPS / 坐标 / 生物群系）
- 音效 + 背景音乐（WebAudio 程序化合成）

## 🛠️ 技术栈

- **渲染**: Three.js (WebGL) — 16x16 程序化纹理图集
- **世界**: 16x16x72 区块系统，贪心面剔除 + 邻居面剔除
- **物理**: AABB 碰撞检测 + DDA 体素射线追踪
- **音频**: WebAudio API 程序化合成
- **存储**: localStorage (世界修改增量 + 玩家状态)

```

├── index.html          # 入口
├── css/style.css       # 像素风 UI
├── lib/three.min.js    # Three.js
└── js/
    ├── constants.js    # 常量与全局状态
    ├── noise.js        # Simplex 噪声
    ├── blocks.js       # 方块/物品注册表
    ├── textures.js     # 程序化纹理生成
    ├── worldgen.js     # 生物群系与地形生成
    ├── world.js        # 区块管理与网格构建
    ├── physics.js      # 碰撞与射线
    ├── sound.js        # 音效合成
    ├── sky.js          # 昼夜循环
    ├── entities.js     # 生物/掉落物/粒子
    ├── inventory.js    # 背包与合成
    ├── player.js       # 玩家控制器
    ├── ui.js           # 界面管理
    ├── save.js         # 存档系统
    └── main.js         # 主循环
```
