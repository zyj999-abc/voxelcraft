# VoxelCraft — 浏览器体素沙盒游戏

一款**完全运行在浏览器中**的类 Minecraft 体素沙盒游戏。纯原生 JavaScript + Three.js (WebGL) 实现，
**零依赖后端、零外部资源** — 全部材质均由程序化生成，打开即玩。

> 原创实现，与 Mojang / Microsoft 无关。

## 🎮 在线游玩

**[点击这里开始游戏](https://zyj999-abc.github.io/voxelcraft/)**

推荐使用 Chrome / Edge / Firefox 最新版，需要 WebGL 支持。

## ✨ 核心特性

### 世界生成
- 无限程序化地形：大陆噪声 + 山脊噪声 + 细节噪声
- 7 种生物群系：海洋 / 沙滩 / 平原 / 森林 / 沙漠 / 针叶林 / 山地
- 立体洞穴系统（ spaghetti + cheese 双通道雕刻）
- 矿脉生成：煤 / 铁 / 金 / 钻石，按深度分布
- 植被：橡树 / 白桦 / 云杉 / 仙人掌 / 花草
- 世界种子支持（相同种子 = 相同世界）

### 方块与交互
- 50+ 种方块，带硬度 / 工具需求 / 掉落规则
- 破坏进度动画 + 粒子效果
- 方块放置 / 选取（中键）
- 环境光遮蔽 (AO) 平滑光照
- 半透明水面渲染
- **箱子**：27 格存储，独立物品空间，存档保留
- **门**：右键开关，上下两格联动
- **床**：夜晚睡觉跳到清晨，雷雨夜也可入睡

### 生存玩法
- 生命值 / 饥饿值 / 氧气（水下呼吸）/ 盔甲值
- 摔落伤害 / 溺水伤害 / 火焰伤害
- 死亡掉落物品（含盔甲）+ 重生
- 完整合成系统：2x2 随身合成 + 3x3 工作台
- 熔炉冶炼：矿石 → 锭，生肉 → 熟肉
- 40+ 合成配方，5 材质 x 5 类型工具（含锄头）
- **工具耐久**：使用消耗，归零损坏
- **盔甲系统**：皮革 / 铁 x 头盔-胸甲-护腿-靴子，按防御点数减伤
- **农业**：锄头开垦耕地 → 播种小麦 → 生长 4 阶段 → 收获
- **骨粉**：右键催熟作物
- **食物**：面包 / 熟猪排 / 牛排 / 熟鸡肉，各异的饥饿恢复

### 生物（7 种）
- 被动：猪（猪排）、**牛**（牛皮+牛肉）、**羊**（羊毛+生羊肉）、**鸡**（羽毛+生鸡肉）
- 敌对：僵尸（近战追踪）、**骷髅**（远程射箭，掉落骨头+箭）、**苦力怕**（接近引爆，破坏地形）
- 简单 AI：游荡 / 追击 / 攻击 / 逃跑
- **箭矢实体**：抛物线弹道，命中判定
- 掉落物实体：旋转漂浮，靠近拾取

### 世界交互
- TNT 爆炸（连锁引爆 + 破坏地形）
- 火把照明
- 昼夜循环：日月星辰 / 程序化云层 / 日落色彩
- **天气系统**：晴天 / 雨天 / 雷暴，雷暴伴随闪电与音效
- 动态雾效（跟随渲染距离）

### 界面与系统
- 类 MC 像素风 UI：标题画面（随机 splash）/ HUD / 背包 / 合成 / 熔炉 / 箱子
- **盔甲栏 HUD**（着甲时显示）+ 背包内 4 个盔甲槽
- **睡眠渐变过渡**动画
- 创造模式：飞行（双击空格）/ 无限方块 / 免伤害 / 创造物品栏（搜索）
- 聊天命令：`/give` `/time` `/tp` `/gamemode` `/weather` `/help`
- 存档系统：localStorage 自动保存 + 手动保存（含盔甲耐久 / 箱子内容 / 作物状态）
- F3 调试信息（FPS / 坐标 / 生物群系）
- 音效 + 背景音乐（WebAudio 程序化合成，20+ 种音效）

## 🛠️ 技术栈

- **渲染**: Three.js (WebGL) — 16x16 程序化纹理图集
- **世界**: 16x16x72 区块系统，贪心面剔除 + 邻居面剔除
- **物理**: AABB 碰撞检测 + DDA 体素射线追踪
- **音频**: WebAudio API 程序化合成
- **存储**: localStorage (世界修改增量 + 玩家状态 + 方块实体)
- **测试**: Playwright 端到端回归测试（70+ 检查项）

```
    ├── entities.js     # 生物/掉落物/箭矢/粒子
    ├── inventory.js    # 背包与合成
    ├── player.js       # 玩家控制器
    ├── ui.js           # 界面管理
    ├── save.js         # 存档系统
    └── main.js         # 主循环
```
