关于 VoxelCraft

VoxelCraft 是一款完全运行在浏览器中的体素沙盒游戏，灵感来自经典沙盒玩法。

全部代码与材质均为原创、程序化生成，不包含任何官方游戏资源，与 Mojang / Microsoft 无关。

技术栈：原生 JavaScript + Three.js (WebGL)
